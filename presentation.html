What is GitHub Pages?

GitHub Pages is a static website hosting service.

  • Hosts websites directly from repositories
  • Supports public deployment
  • Works well with Markdown and Jekyll

Why GitHub Pages?

It allows developers and students to publish projects online without traditional hosting.

What is Jekyll?

Jekyll is a static site generator built into GitHub Pages.

  • Converts Markdown into HTML
  • Uses layouts and themes
  • Helps organize static websites

What is Reveal.js?

Reveal.js is a framework for creating presentations using HTML.

  • Supports horizontal navigation
  • Supports vertical navigation
  • Allows themes, images, and animations
